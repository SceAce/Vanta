# ADR-0001: 公开资料引用边界

Status: accepted

Date: 2026-04-26

## Context

Vanta 会参考现有 Agent CLI、二进制分析工具和公开分析文章的设计经验。项目需
要明确哪些材料可以使用，哪些材料不能进入仓库，以降低开源和长期维护风险。

## Decision

Vanta 允许参考公开分析文章中的架构思想、交互模式、模块边界，以及文章中
合法发布的代码片段。

Vanta 禁止复制、移植或改写泄露源码和其他未授权源码进入仓库。

项目文档可以把 Claude Code、Codex 等作为体验对标，但不能复制其私有实现、
品牌资产或非授权源码。

## Consequences

1. 架构设计可以吸收公开资料中的思想。
2. 代码实现需要保持来源可解释。
3. 未来如引入第三方代码片段，必须保留来源、许可证和适用边界。
